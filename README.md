Entry for make.fun's "Warning Label for Humans: One Line, Big Laugh" bounty ($5 in USDC).

The entry is a single warning label, 140 characters — inside the 160-character limit: **WARNING: This human runs on 4 hours of sleep, 3 coffees, and pure spite. Do not shake. May confidently explain things Googled 5 minutes ago.**

It reads like a real safety label — sleep, coffee and spite as the fuel, "Do not shake" as the handling instruction, and the confidently-wrong Google expert as the recognisable human flaw. Funny first, plausible second.

`main.py` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints the same line to stdout. Deterministic: no network, no randomness, no clock.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
